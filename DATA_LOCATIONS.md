# QM640 Food Affordability AI - Data and Artifact Locations

Repository: https://github.com/piyushsoni88/qm640-food-affordability-ai

| Item | Repository location | What it contains | Why it matters |
|---|---|---|---|
| Final executed notebooks | `notebooks/FinalNotebooks/` | Notebook 01 through Notebook 10 used for the final aligned analysis. | Main reproducible code chain for acquisition, cleaning, EDA, modelling, explainability, HFASI, scenarios, and final results. |
| Latest notebook outputs | `QM640_Food_Affordability_notebookData/content/drive/MyDrive/QM640_Food_Affordability/reports/notebook_outputs/` | Execution summaries, model metrics, hypothesis outputs, decision-loss tables, and generated evidence CSVs. | Provides the numeric results used in the final report. |
| Latest figures | `QM640_Food_Affordability_notebookData/content/drive/MyDrive/QM640_Food_Affordability/reports/notebook_outputs/figures/` | PNG figures generated by the final notebook run. | Visual evidence for EDA, forecasting, shock classification, explainability, HFASI, and scenarios. |
| Cleaned state dataset | `data/processed/cleaned_state_monthly.csv.gz` | Cleaned state-month-commodity panel with price, climate, production, wage, arrival, lag, and target fields. | Primary cleaned dataset required for submission and modelling. |
| Cleaned national dataset | `data/processed/cleaned_national_monthly.csv.gz` | Cleaned national monthly CPI and macro modelling panel. | Used for national food CPI forecasting and long-horizon planning. |
| State modelling panel | `data/processed/modeling_state_monthly.csv.gz` | State-level modelling-ready panel before final cleaning outputs. | Reproducibility support for state/commodity modelling. |
| National modelling panel | `data/processed/modeling_monthly_national.csv.gz` | National modelling-ready panel. | Reproducibility support for CPI and macro forecasting. |
| AGMARKNET monthly aggregate | `data/processed/agmarknet_monthly_state_commodity.csv.gz` | Monthly state-commodity AGMARKNET price aggregate. | Core price panel behind state-level analysis. |
| Source inventory | `data/processed/source_inventory.csv` | List of curated source files audited by Notebook 01. | Documents data lineage. |
| Genuine arrivals data | `data/external_required/agmarknet_enam_arrivals.csv.gz` | Integrated AGMARKNET/eNAM arrival quantity file. | Required supply-side variable for the final aligned hypothesis. |
| Arrivals coverage file | `data/external_required/agmarknet_enam_arrivals_coverage.csv` | Coverage summary for the arrivals data. | Documents arrival data scope and completeness. |
| Final report Word file | `reports/Piyush_Soni_QM640_Final_Report.docx` | Final report prepared using the final-report template. | Submission report source document before PDF export. |
| Interim report files | `reports/Piyush_Soni_QM640_Interim_Report_*.docx` | Prior/interim report versions. | Continuity evidence from synopsis/interim work. |
| Report assets | `reports/report_assets/` | Diagrams and report support graphics. | Visual material used in reporting. |
| Notebook builders/scripts | `scripts/25_build_synopsis_aligned_notebook_01.py` through `scripts/36_build_synopsis_aligned_interim_report.py` | Scripts that generated aligned notebooks and report artifacts. | Reproducibility and audit support. |

Note: Very large raw HCES/PLFS files under `data/raw/` are not the cleaned modelling dataset and may exceed GitHub's ordinary file-size limits. The required cleaned and modelling datasets are the compressed files under `data/processed/`.
